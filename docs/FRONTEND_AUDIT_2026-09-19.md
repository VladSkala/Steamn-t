## Ограничения, которые нельзя устранить только frontend

1. Реальное удаление уведомлений не реализовано: в исходном API доступны только получение и отметка прочитанного. Удаление из БД требует нового серверного метода, что запрещено текущим заданием. Фальшивое локальное «удаление», после которого уведомления возвращаются, не добавлялось.
2. Переведены все разделы настроек, а не весь сайт. Выбор языка настроек хранится в этом браузере; он не синхронизируется между устройствами. Сервер поддерживает только en/uk, поэтому русский не отправляется в его поле языка. Тексты пользовательского контента и ошибки, пришедшие непосредственно от API, не переводятся автоматически.
3. Репорты и бандлы убраны из интерфейса; их серверные модели, маршруты и старые данные остаются неизменными по требованию не менять backend.
4. Браузерная проверка выполнена в Chromium. Нативные всплывающие списки и аудиоконтролы могут немного отличаться в Firefox/Safari и на телефонах. Запись с реального микрофона не проверялась; проверена отправка и отображение аудиофайла.
