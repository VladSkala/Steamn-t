# Галерея Steamn’t

[← К основному README](../../README.md) · [Маршруты и размеры снимков](manifest.json)

Это снимки локальной установки с `seed_full_demo`: 31 настольный экран сайта, 3 мобильных и 7 экранов Django admin. Изображения сняты автоматически скриптом [`scripts/capture-screenshots.mjs`](../../scripts/capture-screenshots.mjs). Инструкция по повторному запуску есть в [основном README](../../README.md#переснять-проект-одной-командой).
